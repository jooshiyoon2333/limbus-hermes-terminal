# HERMES · 赫尔墨斯终端

一款以《边狱巴士》与食指意象为灵感的 Android 个人终端。把日常待办写成指令，用纸条、计时与提醒安排自己的节奏。

## 功能

- **指令与提醒**：编录日常任务、履行期限与自定义内容，接收到期催告。
- **桌面组件**：纸条、时钟、倒计时、秒表及指令簿；提供多种尺寸，支持添加多个组件。
- **终端外观**：自定义背景、桌面小物件、声音与音乐。
- **随行者 · 里恩**：应用内桌宠，两种形态、切换过渡、点按互动与碰撞攻击动画。
- **微光与彩蛋**：时间闪烁、数码风显示与乱码彩蛋，可在设置中调整。
- **本地记录**：指令、设置及导入素材保存在本机，支持归档与备份。

## 初次接入

1. 启动应用，阅读接入须知与操作规程。
2. 双击终端读取译文，点击乌头花进入指令清单。
3. 双击食指标记打开「终端校准」，设置提醒、外观与随行者。
4. 长按手机桌面，在小组件列表找到「赫尔墨斯终端」，添加需要的组件。

## 提醒与后台设置

- 允许系统通知，并开启需要的通知类别。需要准点提醒时，检查「闹钟和提醒」权限。
- 小米等系统可能要求允许应用自启动、放宽后台电量限制；应用内「后台接续设置」可进入应用详情。
- 开机或应用更新后，静默恢复后续指令。关机期间错过的催告不补播，过期指令仍保留在清单中。
- 开机恢复不会主动打开界面或播放音乐。首次安装后请至少手动启动一次。
- 强行停止、关机、勿扰及厂商后台管理可能影响提醒，请先用短期任务确认自己手机上的实际表现。

桌宠目前在应用界面内活动。
